# Iterative Semantic Decoding for Short Block Codes

[![Model Weights](https://img.shields.io/badge/Model_Weights-Hugging_Face-yellow.svg)](https://huggingface.co/jhao666/sec-iter-model)

This is the official repository for **"Iterative Semantic Decoding for Short Block Codes"**.

## Overview

We propose an iterative semantic decoding framework for reliable natural-language transmission over noisy channels using short block codes. The receiver iteratively combines channel decoding with language-model-based denoising, using verified semantic information to improve subsequent decoding iterations.
